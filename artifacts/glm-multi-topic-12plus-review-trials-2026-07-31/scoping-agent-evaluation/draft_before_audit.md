# 大语言模型自主 Agent 评测研究的范围综述

## 摘要

随着大语言模型（LLM）能力的涌现，其作为自主智能体（Agent）的应用场景日益广泛，从通用任务解决到复杂的社会模拟。然而，如何系统性地评估 Agent 的规划、工具使用、记忆管理、协作能力及长期任务表现，已成为当前研究的关键挑战。本文旨在对 LLM Agent 评测研究进行范围综述。研究方法采用范围综述模式，仅检索 arXiv 预印本平台，经标题摘要筛选后纳入 12 篇可读取全文的文献。综合分析表明，现有研究已从单一的任务性能评估转向对 Agent 架构模块（如规划、记忆、行动）的系统性评估，并涌现出如 API-Bank 等针对工具使用的标准化基准。然而，当前评估体系仍面临短期交互与长期动态行为评估脱节、主观评价方法（如 LLM-as-a-Judge）的复杂性、以及企业级特定场景评估缺失等局限。本文总结了现有评测框架、指标体系及有效性风险，为后续 Agent 评测研究提供了参考。

**关键词**：大语言模型；自主智能体；范围综述；工具使用；规划能力；评估基准

## 引言

大语言模型（LLM）的快速发展使其不再局限于文本生成，而是逐渐演变为具备感知、决策与行动能力的自主智能体。LLM Agent 能够通过模块化架构（如 Profile、Memory、Planning、Action）模拟人类的认知过程，在软件工程、科学研究、社会模拟等领域展现出巨大潜力 [P4][P5]。然而，Agent 的能力评估远比单一模型的文本生成任务复杂，它不仅涉及模型本身的推理能力，还涉及多模态感知、工具调用、长期记忆维护以及多智能体协作等动态交互能力 [P9]。

现有的评测研究主要集中在两个维度：一是对 Agent 架构组件（如规划、记忆）的评估，二是对特定应用场景（如工具使用、临床辅助）的基准测试。尽管已有大量综述性工作 [P1][P2][P3]，但针对 Agent 评测这一细分领域的系统性范围综述仍显不足。特别是关于如何量化评估 Agent 的长期规划能力、工具使用的鲁棒性以及多智能体协作中的社会性指标，尚缺乏统一的框架。

本文旨在回答以下核心问题：LLM Agent 的规划、工具使用、记忆、协作与长期任务能力如何被评价？现有基准的任务设计、指标、可复现性和有效性风险是什么？通过系统梳理相关文献，本文试图厘清当前 Agent 评测的研究版图，识别关键挑战与未来方向。

## 方法

### 研究设计
本研究采用范围综述模式，旨在对特定研究领域的研究现状进行全景式描述，而非穷尽性系统综述。研究设计遵循 PRISMA-ScR 指南原则，重点关注研究范围、研究类型、概念定义及证据版图。

### 信息来源与检索策略
根据真实方法记录，本研究仅使用 arXiv 预印本平台作为数据源。检索策略基于研究问题构建，关键词涵盖“Large Language Model”、“Agent”、“Autonomous Agent”、“Evaluation”、“Benchmark”、“Tool Use”、“Planning”、“Memory”、“Multi-agent”等。检索未设置时间限制，以捕捉该领域的最新进展。

### 筛选与纳入
初步检索后，依据标题和摘要进行筛选。最终纳入 12 篇文献进行全文阅读与分析。纳入文献类型包括综述性文章 [P1][P2][P3][P4][P5][P6][P7][P9][P10][P11]、基准测试研究 [P8] 以及评论性文章 [P12]。排除标准为：非 arXiv 来源、非英文文献、无法获取全文或与 Agent 评测主题无关的文献。

### 数据提取与综合
数据提取基于结构化证据卡，涵盖研究类型、研究目标、评估范围（模型、任务、数据集、指标）、主要发现、局限性及有效性风险。综合分析采用归纳法，将文献按主题进行聚类，识别共识、分歧及异质性来源。

### 研究质量评价
由于纳入文献主要为综述和基准研究，质量评价主要关注其证据强度（高/中）、方法论的严谨性（如是否提供代码/数据）以及结论的边界条件。对于基准研究，重点考察其数据集规模、指标定义及复现性支持。

## 结果

### 文献筛选与研究特征
经过筛选，最终纳入 12 篇文献。其中，综述性文章 10 篇 [P1][P2][P3][P4][P5][P6][P7][P9][P10][P11]，基准测试研究 1 篇 [P8]，评论性文章 1 篇 [P12]。文献发表时间主要集中在 2023 年至 2024 年，反映了该领域的快速迭代。

### 主题综合

#### 1. 规划与长期任务能力的评估
规划能力是 Agent 实现自主任务解决的核心。现有研究普遍认为，Agent 的规划模块通常与记忆和行动模块紧密耦合 [P4][P5]。评估规划能力的方法主要分为两类：一是基于内部推理的评估，通过任务完成率和推理链质量来衡量；二是基于外部环境的评估，通过模拟复杂工作流或长期任务序列来观察 Agent 的决策轨迹 [P11][P12]。

在长期任务评估方面，现有的静态基准（如 MMLU）往往难以捕捉 Agent 在长时间跨度内的性能漂移或累积效应 [P9]。Agent-Based Modeling (ABM) 被引入作为一种评估长期行为的有效手段，通过模拟 Agent 在虚拟社会或经济系统中的交互，观察其长期适应性和群体涌现行为 [P11]。然而，LLM 本身在长文本建模上的局限性（如“Lost in the middle”问题） [P7]，使得 Agent 在处理超长上下文时的规划能力面临挑战 [P3]。

#### 2. 工具使用的多维评估
工具使用是 Agent 赋能现实世界的关键。现有研究将工具使用评估定义为“三问”：是否调用工具、调用哪个工具、如何使用工具 [P10]。API-Bank 等基准测试通过构建包含 73 个真实世界 API 的环境，量化了模型在 API 调用、检索和规划层面的能力 [P8]。

评估指标呈现出多维度特征。除了传统的任务成功率，研究者引入了更细粒度的指标，如 API 调用正确率、工具选择准确率、检索准确率（MRR, NDCG）以及参数名称的 F1 分数 [P8][P9]。研究发现，即使是较小的模型（如 Alpaca-7B）也具备一定的 API 调用能力，但在复杂的检索和规划任务上表现较弱 [P8]。此外，工具文档的时效性和多模态工具的语义理解能力也是当前评估中的难点 [P10]。

#### 3. 记忆与上下文管理
记忆模块负责存储和检索信息，是维持 Agent 连贯性的基础。评估重点在于 Agent 是否能从历史交互中提取关键信息，并在当前任务中有效利用 [P9]。记忆结构通常被划分为短期记忆、长期记忆和混合记忆 [P4][P5]。

然而，记忆评估往往隐含在任务成功率的计算中，缺乏独立的评估指标。Hallucination（幻觉）是评估记忆完整性的关键风险指标，特别是在多模态 Agent 中，模型可能生成与图像内容不一致的描述 [P3]。此外，上下文窗口的限制使得 Agent 在处理海量历史数据时面临“遗忘”或“信息过载”的风险，这直接影响了其规划决策的准确性 [P3][P7]。

#### 4. 协作与多智能体系统
多智能体协作评估关注 Agent 之间的交互质量。评估维度包括语言沟通能力、合作与谈判能力以及角色扮演能力 [P6]。Agent-Based Modeling (ABM) 被广泛用于评估多智能体系统中的社会现象，如从众效应和群体智慧 [P11]。

在协作基准测试中，任务完成率和共识答案常被用作客观指标 [P9]。然而，现有研究多集中于合作场景，对于对抗性交互和复杂社会动态的评估相对较少 [P6]。此外，多智能体系统中的通信开销和同步机制也是影响协作效率的重要因素，但在现有评测中关注不足。

#### 5. 评测框架、指标与有效性风险
在评测框架方面，P9 提出了一种二维分类法，将评估目标分为行为、能力、可靠性和安全性，将评估过程分为交互模式、数据、指标和工具 [P9]。这为构建全面的 Agent 评测体系提供了理论框架。

**指标体系**：现有指标涵盖了从传统的准确率、F1 分数，到基于 Elo 排名的 Chatbot Arena，再到成本和延迟等效率指标 [P1][P2][P7]。针对 Agent 特性，还涌现出 pass^k（一致性通过率）、执行准确率等指标 [P9]。

**有效性风险**：
1.  **幻觉与错误传播**：LLM 的固有缺陷可能导致 Agent 在规划或工具调用中产生幻觉，进而引发连锁错误 [P3][P6]。
2.  **对抗性攻击**：Agent 在面对提示注入或数据投毒攻击时表现出脆弱性，可能导致有害行为 [P6]。
3.  **主观评价偏差**：LLM-as-a-Judge 方法虽然能处理开放性回答，但其主观性和复杂性引入了新的评估风险 [P9]。
4.  **基准静态化**：许多基准测试（如 MedQA）是静态的，无法反映 Agent 在动态环境中的适应能力，特别是在临床等高风险领域，这种差距尤为明显 [P12]。

## 讨论

### 主要发现与解释
本研究发现，LLM Agent 的评测已从单一的模型性能测试转向对复杂系统行为的综合评估。共识在于，Agent 的能力评估必须超越单一的准确率指标，转向对规划、记忆、工具使用和协作等多模块协同能力的考察 [P4][P5][P9]。

工具使用评估的细化（如区分调用、检索和规划）揭示了当前模型在工具编排上的短板，即模型往往缺乏将复杂任务分解为工具调用序列的能力 [P8][P10]。这表明，单纯依靠提示工程可能不足以解决工具使用的复杂性问题，需要结合机制工程或微调训练 [P5]。

在长期任务评估方面，基于模拟环境（ABM）的方法显示出潜力，能够捕捉 Agent 在长时间交互中的行为演变 [P11]。然而，这也暴露了当前评测的一个核心矛盾：静态基准难以评估动态行为，而动态基准的构建成本高昂且难以标准化。

### 异质性、适用性与证据确定性
不同研究在评估方法上存在显著异质性。例如，在工具使用评估中，有的研究侧重于响应质量（Rouge-L） [P8]，有的则侧重于执行正确性 [P9]。这种异质性源于评估目标的不同：前者关注交互体验，后者关注功能实现。

在适用性方面，现有的评测框架多针对通用场景，而在企业级或特定垂直领域（如医疗、法律）的评估标准尚不完善 [P9][P12]。例如，在临床场景中，标准化的临床 NLP 基准（如 MedQA）无法完全评估 Agent 在复杂医院流程中的表现，需要引入高保真模拟和基于真实电子病历（EHR）的评估 [P12]。

证据确定性方面，综述类文献提供了高强度的理论框架和分类 [P4][P5][P9]，而基准测试文献提供了具体的量化数据和代码支持 [P8]。然而，部分综述指出，现有评测往往缺乏对 Agent 长期记忆维护和跨会话一致性的深入考察 [P3][P9]。

### 本综述的局限
作为一项范围综述，本研究存在以下局限：
1.  **数据源限制**：仅检索 arXiv 平台，可能遗漏了会议论文集或期刊中的相关研究。
2.  **样本量限制**：最终纳入 12 篇文献，样本量较小，可能无法完全覆盖该领域的所有研究。
3.  **主观性**：在文献筛选和主题综合过程中，仍存在一定的主观判断空间。

### 研究与实践启示
1.  **构建动态与长期评测基准**：未来的研究应致力于开发能够评估 Agent 长期行为和动态适应能力的基准，如基于 Agent-Based Modeling 的长期模拟环境 [P11][P12]。
2.  **细化工具使用评估指标**：需要建立更细粒度的工具使用评估标准，特别是针对参数正确性和检索效率的量化指标 [P8][P9]。
3.  **关注企业级与安全评估**：在通用评测之外，应加强对企业级场景（如角色权限、合规性）和安全性（如对抗攻击、幻觉控制）的评估研究 [P6][P9]。
4.  **改进评估方法**：探索更客观、更高效的评估方法，如结合代码执行验证与 LLM-as-a-Judge 的混合评估模式，以降低主观性风险 [P9]。

## 结论

本文对 LLM Agent 评测研究进行了范围综述。研究表明，Agent 评测已进入多维度、模块化的阶段，涵盖了规划、工具使用、记忆、协作及长期任务等多个维度。API-Bank 等基准测试为工具使用评估提供了标准，而基于 ABM 的模拟则为长期行为评估提供了新思路。然而，当前评估体系仍面临静态基准难以捕捉动态行为、主观评价方法复杂、以及特定领域评估缺失等挑战。未来的研究应致力于构建更全面、更动态、更贴近真实场景的 Agent 评测体系，以推动 LLM Agent 技术的健康发展。
